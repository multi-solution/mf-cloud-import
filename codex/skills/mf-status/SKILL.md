# 状況の確認（Codex 版の入口）

**作業の前に、次の2つをこの順で読む。**

1. `<プラグインのルート>/codex/CODEX.md` … Codex で動かすときの読み替え表
2. `<プラグインのルート>/commands/mf-status.md` … 状況確認の手順（本体）

**プラグインのルート**＝このファイルの3階層上のフォルダ。

本体の手順に**厳密に**従う。**読み取りだけを行い、登録・修正・添付は一切しない。**
設定が無いときに案内するコマンドは `$mf-setup`。
