# 初期設定（Codex 版の入口）

**作業の前に、次の3つをこの順で読む。**

1. `<プラグインのルート>/codex/CODEX.md` … Codex で動かすときの読み替え表
2. `<プラグインのルート>/commands/mf-setup.md` … 初期設定の手順（本体）
3. `<プラグインのルート>/skills/mf-cloud-import/SKILL.md` … 記帳の決まりごと（本体が参照する）

**プラグインのルート**＝このファイルの3階層上のフォルダ。

本体の手順に**厳密に**従う。特に次の読み替えに注意する。

- `mfc_ca` のツールが見つからないときの案内は、本体の「claude.ai のコネクタ設定」ではなく、
  読み替え表 4 の「Codex の設定 → MCP サーバー」の手順を案内する
- 事業者の切り替えは、読み替え表 4 の `codex mcp logout` → `codex mcp login`
- 最後に案内するコマンドは `$mf-status` と `$mf-import`
