# 記帳の実行（Codex 版の入口）

**作業の前に、次の3つをこの順で読む。**

1. `<プラグインのルート>/codex/CODEX.md` … Codex で動かすときの読み替え表
2. `<プラグインのルート>/commands/mf-import.md` … 記帳の流れ（本体）
3. `<プラグインのルート>/skills/mf-cloud-import/SKILL.md` … 記帳の手順の詳細（本体が「厳密に従う」と指定）

**プラグインのルート**＝このファイルの3階層上のフォルダ。

本体の手順に**厳密に**従う。特に次の読み替えに注意する。

- `tax_review` が `on` のときの `tax-reviewer` エージェントは、読み替え表 3 のとおり
  `agents/tax-reviewer.md` を読んで**自分で**レビューする
- 承認テーブルを出したら**必ず止まる**。利用者が「実行」と答えるまで登録系のツールを呼ばない
- 1件記帳が成功するたびに、その場で `ledger.py record` を実行する（添付を待たない）
