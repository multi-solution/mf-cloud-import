# MFクラウド記帳（Codex 版の入口）

このスキルの本体は Claude Code 版と共通のファイルにある。**作業の前に、次の2つをこの順で読む。**

1. `<プラグインのルート>/codex/CODEX.md` … Codex で動かすときの読み替え表
2. `<プラグインのルート>/skills/mf-cloud-import/SKILL.md` … 記帳の手順（本体）

**プラグインのルート**＝このファイルの3階層上のフォルダ（`codex/skills/mf-cloud-import/` の上）。

本体の手順に**厳密に**従い、Claude 固有の書き方だけを読み替え表のとおりに置き換える。
本体と読み替え表が食い違うように見えるときは、**安全な側**（止まる・確認する側）を選ぶ。

本体の「スクリプトはこのスキルファイルの2階層上の `scripts/`」は、本体のファイル
（`skills/mf-cloud-import/SKILL.md`）から見た位置。つまり `<プラグインのルート>/scripts/` のこと。
