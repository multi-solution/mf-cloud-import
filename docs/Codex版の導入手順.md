# Codex（ChatGPT）版の導入手順【試験提供】

ChatGPT をお使いの方向けに、このプラグインを **Codex（ChatGPT のアプリに入っているAIの作業機能）** で使う手順です。
中身の手順書は Claude 版と共通で、記帳の決まりごと（承認してから登録する・証憑のない経費は記帳しない・
同じ領収書を二度記帳しない）はまったく同じです。

> ⚠️ **Codex 版は試験提供です。** Claude 版ほど実際の帳簿で検証できていません。
> 特に、**PDF の読み取り**と**勘定科目の判定の精度**は、Claude 版と同じとは限りません。
> 必ず **[5. まず少量で試す](#5-まず少量で試す)** の手順で確かめてから、ふだんの記帳にお使いください。

---

## 必要なもの

- **Codex が使える ChatGPT のご契約**（ChatGPT のデスクトップアプリ、または Codex CLI）
- **Git** と **Python 3.9 以上**（Claude 版と同じです。入れ方は [導入マニュアル](導入マニュアル.md) の基本編 Step 1-2）
- **マネーフォワード クラウド会計**のアカウント
- 証憑の自動添付を使う場合：マネーフォワードの開発者アプリ登録（Claude 版と同じ。[導入マニュアル](導入マニュアル.md) の応用編）

> **ChatGPT のウェブ版（chatgpt.com）だけでは使えません。** パソコンの中の領収書とスクリプトを使うため、
> パソコンで動く Codex（デスクトップアプリか CLI）が必要です。

---

## 1. プラグインを入れる

ターミナルで次の2行を実行します。

```bash
codex plugin marketplace add multi-solution/mf-cloud-import
```

```bash
codex plugin add mf-cloud-import@mf-cloud-import
```

> **`codex: command not found` と出たとき（Mac）**：ChatGPT アプリに入っている Codex を、場所を指定して使います。
> 上の2行の `codex` を `/Applications/ChatGPT.app/Contents/Resources/codex-cli/bin/codex` に置き換えて実行してください。
> 「could not create PATH aliases」という注意が出ることがありますが、動作には影響しません。

入れたあとは、**ChatGPT アプリ（または Codex）を再起動**してください。

---

## 2. マネーフォワード クラウド会計につなぐ

Claude 版と同じく、接続設定は**同梱していません**。ご自身のアカウントで、マネーフォワード公式の接続先を登録します。
接続名は必ず **`mfc_ca`** にしてください（手順書がこの名前を前提にしています）。

**画面で行う場合**

1. Codex の **設定 → MCP サーバー → サーバーを追加**
2. 名前に `mfc_ca`、URL に `https://beta.mcp.developers.biz.moneyforward.com/mcp/ca/v3` を入れて保存
3. アプリを再起動し、`mfc_ca` の **認証（Authenticate）** を押す
4. マネーフォワードの画面が開くので、**記帳したい事業者が選ばれていることを確かめてから**許可する

**ターミナルで行う場合**

```bash
codex mcp add mfc_ca --url https://beta.mcp.developers.biz.moneyforward.com/mcp/ca/v3
```

```bash
codex mcp login mfc_ca
```

> 画面の項目名は、アプリの版によって少し違うことがあります。
> 認可はマネーフォワードの画面上でご自身が行います。認可情報がプラグインや作者に渡ることはありません。

**事業者を切り替えるとき**は、いったん切断してからつなぎ直します。

```bash
codex mcp logout mfc_ca
```

```bash
codex mcp login mfc_ca
```

## 3. 証憑の自動添付を有効にする（任意）

Claude 版と同じスクリプトを、**ご自身でターミナルから**実行します（Client Secret を入力するため、AIには実行させません）。

```bash
python3 ~/.codex/plugins/cache/mf-cloud-import/mf-cloud-import/0.1.0/scripts/oauth_init.py
```

> `0.1.0` の部分は、入れたプラグインの版です。見つからないときは
> `~/.codex/plugins/cache/mf-cloud-import/mf-cloud-import/` の中のフォルダ名に合わせてください。
> **Claude 版ですでに設定済みなら、この手順は不要です**（同じ `~/.mfc/credentials.json` を使います）。

---

## 4. 初期設定

領収書を入れるフォルダを、Codex で**作業フォルダとして開き**、次のように頼みます。

```
$mf-setup で初期設定をして
```

`$` を入力すると、使えるスキルの一覧が出ます。「MFクラウド記帳：初期設定」を選んでも同じです。

| Claude 版のコマンド | Codex 版の呼び方 |
|---|---|
| `/mf-cloud-import:mf-setup` | `$mf-setup` |
| `/mf-cloud-import:mf-status` | `$mf-status` |
| `/mf-cloud-import:mf-import` | `$mf-import` |

### 途中で「許可」を求められます

Codex は安全のため、パソコンの外との通信や、作業フォルダの外への書き込みを、そのつど確認してきます。
このプラグインでは次の場面で確認が出ます。**AI が何のための操作かを先に説明するので、内容を見てから許可してください。**

| 場面 | 何をしているか |
|---|---|
| 接続の確認（`preflight.py`） | 証憑の添付が使えるか、マネーフォワードに問い合わせる |
| 証憑の添付（`attach_voucher.py`） | 承認した仕訳に、領収書ファイルをアップロードする |
| 鍵の更新 | マネーフォワードの鍵（`~/.mfc/credentials.json`）の期限を延ばす |

許可しなかった場合、その工程は止まります。帳簿が中途半端に書き換わることはありません。

## 5. まず少量で試す

**初回は領収書1〜2件で実行し、結果をマネーフォワードの画面で確認してください。**
科目・税区分・インボイス区分が意図どおりかを確かめてから、まとめて処理してください。

```
$mf-import でこのフォルダの領収書を記帳して
```

確認表が出たら内容を見て、よければ「**実行**」と答えます。「実行」と答えるまで、帳簿には何も登録されません。

> **Claude 版もお使いの方へ**：同じ領収書フォルダを Claude 版と Codex 版の両方で処理しても、
> 処理済み台帳（`.mf-cloud/ledger.json`）を共有するため、**二重に記帳されることはありません。**

## データの扱い（必ずお読みください）

### 作者には送られません

Claude 版と同じく、このプラグインは外部サーバーを持たず、**作者にデータが送られることはありません。**

### ただし、OpenAI 社は経由します

Codex はあなたのパソコンで動きますが、**読み取りと判定は OpenAI 社のクラウドで行われます。**
領収書の中身だけでなく、事業者名・連携明細・過去の仕訳・取引先・勘定科目なども OpenAI 社へ送られます。
（Claude 版で Anthropic 社に送られるものと同じ範囲です）

### だから、契約と設定を確認してください

- **個人向けのご契約**（Free・Plus・Pro など）の方は、ChatGPT の **設定 → データコントロール** で
  「すべての人のためにモデルを改善する」を**オフ**にしてください。オンのままだと、内容が学習に使われることがあります。
- **他人のデータを扱う場合**（税理士・記帳代行・複数の会社の経理）は、組織として設定を管理できる
  **ChatGPT Business 以上のご契約**をおすすめします。
- 保存期間などの詳細は、OpenAI 社の公式の案内をご確認ください。契約の種類によって扱いが変わります。

> 税理士・社会保険労務士など守秘義務を負う立場の方は、**所属会のガイドラインと、顧問先への説明の要否を必ずご確認ください。**
> 本プラグインはその判断を代わりに行うものではありません。

## うまく動かないとき

| 症状 | 確かめること |
|---|---|
| `mfc_ca` が見つからないと言われる | 手順 2 の登録と「認証」が済んでいるか。名前が `mfc_ca` になっているか |
| 別の事業者の名前が表示される | 手順 2 の「事業者を切り替えるとき」で、つなぎ直す |
| 古い手順（CSV を作る）で動き始める | 以前に入れた同じ名前の古いスキル（`~/.agents/skills/mf-cloud-import` など）が残っていないか。残っていれば、名前を変えるか外してください |
| `source-command-mf-status` というスキルが一覧にある | Codex が自動で作る写しです。使わず、`$mf-status` を使ってください |
| PDF の金額が読み取れない | 推測で記帳はせず「要確認」になります。写真（JPG・PNG）で保存し直すと読める場合があります |

不具合の報告は、このリポジトリの **Issues** へお願いします（マネーフォワード社ではお答えできません）。
